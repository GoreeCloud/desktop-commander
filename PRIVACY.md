# Privacy

GoreeCloud Desktop Commander is an early, local-only MCP source import. The modified entrypoint disables inherited upstream telemetry, startup feature flag polling, marketing onboarding, raw local tool-history storage and automatic browser download.

This is not comprehensive network isolation: inherited file-conversion functions, dependencies and commands requested by authorized AI clients may access the network and local filesystem. No GoreeCloud-hosted account or remote device pairing, automatic synchronization, or consent UI has been implemented.

Treat the MCP process and outputs as private. Grant it only least-privileged access and never attach untrusted clients or public endpoints. GoreeShield privacy governance requirements remain to be integrated and validated.
