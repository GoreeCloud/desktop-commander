# Roadmap

1. Verify source, lockfile, dependency integrity, local build and comprehensive regression tests.
2. Harden commands, permissions, local data retention, file conversion and network egress.
3. Develop an original, opt-in self-hosted remote broker; do not copy proprietary remote service source.
4. Integrate and test GoreeCloud Identity authorization, GoreeShield consent, Wardveil security controls and GoreeCloud Mesh APIs.
5. Establish premium GoreeCloud UI, Linux-native target compliance and Android development after reviewed requirements.
6. Test recovery, device revocation, updates, monitoring, container suitability and staged deployment.

These are plans, not delivered features or release promises.
